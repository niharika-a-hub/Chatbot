# Simple ChatBot Website 🤖

This is a basic chatbot built using **HTML, CSS, and JavaScript**.  
It responds to simple queries like "hello", "name", "services", and "bye".  

## 🚀 Demo
Check the live site here: [Chatbot Website](https://your-username.github.io/chatbot-website/)

## ⚙️ Features
- Greets the user
- Tells its name
- Explains services
- Ends conversation with "bye"
- Simple & lightweight (no backend needed)

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
